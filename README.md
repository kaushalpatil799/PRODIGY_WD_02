
# ChronoX - Stopwatch Web Application

A colorful and responsive stopwatch web application developed as Task 02 of the Prodigy InfoTech Web Development Internship.

## Project Overview

ChronoX is a browser-based stopwatch designed to measure elapsed time and record lap timings. It features a modern interface, animated timer ring, session statistics and responsive layouts for desktop and mobile devices.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Start, pause, resume and reset stopwatch
- Digital timer with hours, minutes, seconds and centiseconds
- Record and display lap times
- Track total time, average lap and best lap
- Clear lap history without resetting the timer
- Export lap history to CSV
- Switch between dark and light themes
- Keyboard shortcuts for timer controls
- Responsive design for mobile and desktop
- Animated gradients and interactive UI

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser.
4. For a better development experience, use the Live Server extension.

## Keyboard Shortcuts

- Space: Start or pause
- L: Record a lap while running
- R: Reset the stopwatch
